# **App Name**: MediForm Excel Generator

## Core Features:

- Patient Info Input: Input fields for patient's name, address, and reason for appointment.
- Detailed Problem Description: An editable, multi-line text field to accurately describe the medical problem.
- Generate Excel File: Button to trigger the generation of an Excel file from the collected form data.
- Automated Download: Automatic download of the Excel file upon successful form submission.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to evoke trust and calmness.
- Background color: Light grey (#F0F4F8) to provide a clean, professional look.
- Accent color: Muted green (#81C784) to highlight important actions like 'Submit'.
- Body and headline font: 'PT Sans' sans-serif for clear readability in form labels and content.
- Simple, professional icons for form fields (e.g., a user icon for name, a location icon for address).
- Clean and structured layout with clearly defined sections for each input field.
